# Brutus Tracker

Session kill stats for Brutus, the cow boss in the Lumbridge cow field, and his Demonic hard mode variant.

An overlay shows kills, last kill time, best time this session, personal best, and kills per hour for each variant. It only reports finished kills. It gives no attack, mechanic, or positioning cues.

Session stats reset when the plugin or client restarts, or when you switch accounts. Your personal best and all-time kill count (read from the game's kill count chat message) are saved per RuneScape profile. Each overlay line can be turned on or off under "Displayed stats".
